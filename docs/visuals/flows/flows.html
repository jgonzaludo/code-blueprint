Flow 2: Live while you edit

The window follows the repo. Nobody has to republish anything. This is why the watcher runs locally: that is where the files change.

Save a file

You or Claude, any editor.

→
fs event

chokidar on the root + .blueprint/plans, gitignore respected.

→
Debounce

100 to 200 ms so a burst of saves is one update.

→
Incremental parse

Long-lived TS language service. Only changed files + dependents.

→
Diff vs baseline

git HEAD by default. Block, line and arrow statuses.

→
Push over SSE

/api/events. Map updates in place, layout never jumps.

Target: under about 300 ms from save to repaint on small repos. Existing files keep their positions; only new things get placed.

Flow 4: Plan protocol and the check

Plans are drafts the parser can read, so even proposed arrows are parser-derived. Only intent Claude didn't write yet is a "claim".

plan new

.blueprint/plans/<id>/plan.json
id, title, files, delete, claims

→
plan add

Full proposed file contents into plans/<id>/files/<path>

→
Overlay parse

parse(root, overlay = draft)
diff(disk, draft)

→
Plan view

Dashed: proposed. Hollow arrowhead: claim.

→
Apply

Real edits, or plan apply

→
check

applied graph vs draft graph + claims

confirmed

In draft or claims, and in the applied code. Drawn solid green.

missing: "not in the code"

In draft or claims, not in the applied code. Red dashed with a label. Demo: refundHandler -> recordAudit.

unplanned

In the applied code, touching planned files, but in neither draft nor claims. Amber.

Semantic zoom: one canvas, three levels

Camera is translate + scale on one world. Level of detail switches on scale, so zooming out never shows unreadable code and zooming in never shows summaries.

Project map scale < 0.5

File cards as labeled silhouettes, badges (NEW, ~modified, used by new code), file-to-file arrows. New files in a band on top.

↔
File 0.5 to 0.95

Blocks inside each file, kind + name headers, block-to-block arrows from the calling line to the declaration line.

↔
Code, line for line ≥ 0.95

Exact source with old/new line numbers, + and - lines highlighted, new slots inside existing classes.

Controls: drag to pan, Ctrl or Cmd + wheel to zoom at the cursor, double click a file to zoom to it, click a block to select and zoom (inspector shows Used by / Uses). Zoom limits 0.12 to 2.2. See screenshots 01 to 07.
