Storyline in the Browser

The version that works with any editor or none. One command starts a tiny local server and opens a tab. Save the file and the tab updates.

$ npx storyline src/orders.ts
✓ parsed src/orders.ts (11 blocks, 2 from other files)
✓ watching for changes   http://localhost:4173/?file=src/orders.ts
Storyline: orders.ts
localhost:4173/?file=src/orders.ts
src/orders.tslive, watching file
Select a block to see where it comes up and how it is used.

What you get

The full canvas anywhere: Vim, JetBrains, Zed, a remote box over a forwarded port. No extension and nothing to install beyond running the command.

What you give up

It is a separate window, so clicking a block cannot scroll your editor. You get "copy path:line" or an editor link instead.

Why build it first

It is the cheapest surface, and it is the same page the VS Code panel and the Claude link would show, so nothing is wasted.
