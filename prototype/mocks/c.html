What you get

Click a block and the editor scrolls to those exact lines. Click a line in the editor and the block lights up. External blocks open the real file.

What you give up

Only works in VS Code and its forks, and it is the most work to build. JetBrains, Vim and Zed users need the browser version.

Why it is the best daily driver

It opens once, stays beside your code and follows the file you are in, so there is nothing to remember to open.
