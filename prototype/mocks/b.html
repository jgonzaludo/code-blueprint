Storyline Terminal View

A keyboard-driven view for people who live in the terminal. Click the screen and use the arrow keys, or press the keys shown at the bottom.

storyline src/orders.ts

		

		

			
			
			
			
			
		

	

	

	

		
What you get
A real interactive map without leaving the terminal. Works over SSH, in tmux, in any editor's built-in terminal. No browser, no server.

		
What you give up
Code is shown as short trimmed lines, not full blocks, and there is no free dragging. The canvas is one keypress away for when you want the real thing.

		
Cost to build
The most work of the four. It is a separate renderer from the canvas, so it only makes sense if terminal users ask for it.
