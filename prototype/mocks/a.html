Storyline in Claude Code

What the tool looks like inside a terminal session. Nothing pops up. Claude calls the tool and the answer arrives as text, with the canvas one link away.

claude ~/shop

What you get

The structure in the same place you are already reading. Entry point, call order, and which calls leave the file, with file paths and line numbers.

What you give up

No real code blocks and no dragging. A terminal can show a tree, not a canvas, so the full view lives behind the link.

Why it matters

This is the zero-friction version. It costs one tool call, and the "after an edit" case shows the changed block and who calls it without opening anything.

Mock transcripts. The file, the structure and the line numbers come from the demo project. The edit shown in the second tab and the file path of the canvas are made up for illustration.
